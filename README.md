# SBI-Bank-Loan-Portfolio-Analysis-By-Chinmaya-Shakti-Prasad-Das-Tool-MySQL
A MySQL project analyzing credit risk, customer segmentation, and portfolio health across 60 customers and 70 loans. Features 16 queries covering NPA detection, EMI burden scoring, city-wise rankings, risk flagging, year-wise disbursement trends, and an executive portfolio health scorecard.
